# Use of AI in this project

Since 2026, I will use AI, mainly through Claude Code (Anthropic), as a tool to
review and improve this project: source code, build and test tooling, and
documentation (including the explanations and figures in
`examples/basic_examples/`).

AI tools are not credited as authors. All changes are reviewed by me (or any other contributor) before
they are committed, and authorship and responsibility for this repository
remain to the responsible person who reviewed it and pushed it.

AI is really a surprising and incredible tool for programmers/developers, if used wisely.
I hope those who still love to program and to create algorithms (like me) 
will keep their love to this art in a not distant future.

October, 2026
